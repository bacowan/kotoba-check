# Privacy Policy for Kotoba Check

**Version:** 1.0  
**Effective Date:** 2025-08-15

## 1. Overview
This privacy policy explains how the Kotoba Check Chrome Extension (“the Extension”) collects, uses, and stores information when you use it.

## 2. Data We Collect
When installed and active, the Extension:
- Reads the text content of all webpages you visit.
- Identifies and stores words encountered on those pages.
- Records the list of websites visited (for the sole purpose of avoiding duplicate processing).

## 3. How We Use the Data
We use the collected words and visited website list solely to provide the Extension’s core functionality — tracking which words you’ve encountered and avoiding repeated parsing of the same site.

## 4. Data Storage and Security
All collected data is stored locally in Chrome’s `chrome.storage` API on your device.
- The data is **not** transmitted to any external servers.
- The data is **not** shared with third parties.
- Chrome’s extension storage is isolated from other extensions and websites.

## 5. User Control
You may delete stored data at any time by:
- Uninstalling the Extension, which removes all stored data, or
- Using the Extension’s built-in data reset feature.

## 6. Children’s Privacy
This Extension is not directed toward children under the age of 13 and does not knowingly collect personal information from them.

## 7. Changes to This Policy
We may update this privacy policy from time to time. Changes will be posted at this location, and the “Effective Date” and "Version" above will be updated accordingly.
